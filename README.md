# תרגול מבחני גמר

אפליקציית ווב (PWA) לתרגול פנימית, ילדים וכירורגיה. עובדת בלי אינטרנט אחרי הפתיחה הראשונה, שומרת את ההתקדמות בטלפון, ומושכת עדכוני תוכן כשיש חיבור.

## מבנה
- `index.html` האפליקציה כולה.
- `data/*.json` חבילות התוכן, קובץ לכל מבחן (נוצרות מהסקריפטים ב-`build/`).
- `sw.js`, `manifest.webmanifest`, `icon*` מה שהופך אותה לאפליקציה מותקנת שעובדת אופליין.

## עדכון תוכן
עורכים את `build/<exam>.py` ומריצים `python3 build/<exam>.py`. ההתקדמות של המשתמש נשמרת לפי מזהה כרטיס, אז לא לשנות מזהים של כרטיסים קיימים, רק להוסיף בסוף נושא.

## התקנה בטלפון
האפליקציה צריכה להיות מאוחסנת בכתובת https (למשל GitHub Pages). פותחים את הכתובת ב-Safari, משתף, "הוסף למסך הבית". באנדרואיד: Chrome, תפריט, "התקן אפליקציה".
